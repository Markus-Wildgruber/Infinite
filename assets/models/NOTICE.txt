u2netp.onnx
============

Weights for U^2-Net (small variant, "u2netp"), used on Windows as the
salient-object detection backend for Platform::SubjectMask
(src/platform/win/PlatformWin.cpp), matting `MattingMode::Subject` and
`MattingMode::Person` alike (see that file for why Person maps to the same
model on Windows).

Source:  https://github.com/xuebinqin/U-2-Net
License: Apache License 2.0 (see https://github.com/xuebinqin/U-2-Net/blob/master/LICENSE)
Fetched: https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2netp.onnx
         (an unmodified re-host of the original weights; verified against
         the upstream repo's LICENSE before committing here)

  author = {Qin, Xuebin and Zhang, Zichen and Huang, Chenyang and Dehghan, Masood and Zaiane, Osmar and Jagersand, Martin},
  journal = {Pattern Recognition},

}

Not used on macOS - the macOS build's Platform::SubjectMask uses Vision
instead and never loads this file.


basic-pitch.onnx
================

Weights for Spotify's Basic Pitch note-transcription model ("nmp", ICASSP
2022), used by the Audio to MIDI node (src/nodes/AudioToMidiNode.cpp) through
ONNX Runtime on the CPU provider (src/audio/dsp/BasicPitch.cpp). That file's
windowing, frame-time and note-creation steps are ported from the same
repository's reference Python (basic_pitch/inference.py, note_creation.py).

Source:  https://github.com/spotify/basic-pitch
         basic_pitch/saved_models/icassp_2022/nmp.onnx (unmodified, renamed)
License: Apache License 2.0 (see https://github.com/spotify/basic-pitch/blob/main/LICENSE)
         Copyright 2022 Spotify AB

itself unavailable there.
